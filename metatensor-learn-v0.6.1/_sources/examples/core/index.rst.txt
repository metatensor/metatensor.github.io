Tutorials
=========

Follow step-by-step tutorials to learn how to use metatensor classes to store
your own data, including complex sparsity patterns and gradients handling.

Once you understand the core concepts, you can explore more advanced tutorials
about creating custom ML models using tools from :ref:`metatensor-learn
<learn-tutorials>`.
